### Why benign requests alarm (S1)

- 5× tx.erc20.transfer → risky — You are sending N units of the token at 0x… to 0x…. Make sure you know this address: Copeybara cannot tell a friend from a scammer.
- 2× tx.approve.limited → dangerous — This lets 0x… spend part of this token in your wallet. No protocol you follow publishes that address: this is how wallet drainers work.
- 1× tx.dapp-call → dangerous — This sends your tokens to 0x…, an address no protocol you follow publishes.

### Why benign PTXPhish requests alarm (S1)

- 24× tx.payable-call → risky — This sends ETH to 0x…, an address no protocol you follow publishes.
- 23× tx.other → risky — This creates a new contract. Websites almost never need you to do that.
- 15× tx.erc20.transfer → risky — You are sending N units of the token at 0x… to 0x…. Make sure you know this address: Copeybara cannot tell a friend from a scammer.
- 11× tx.approve.limited → dangerous — This lets 0x… spend part of this token in your wallet. No protocol you follow publishes that address: this is how wallet drainers work.
- 8× tx.eth.transfer → risky — This sends ETH to 0x…, an address no protocol you follow publishes.
- 8× tx.approve.unlimited → dangerous — This lets 0x… spend ALL of this token in your wallet, now and later. No protocol you follow publishes that address: this is how wallet drainers work.
- 1× tx.other → risky — You are sending N units of the token at 0x… to 0x…. Make sure you know this address: Copeybara cannot tell a friend from a scammer.
