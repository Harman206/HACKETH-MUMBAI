# ENS records

All records are ENS text records on your name (ENSv2, Sepolia), read through the UniversalResolver. Codecs live in `@copeybara/core`. Parsers are strict: an unknown field or version is an error, never a guess.

| Key | Written by | Format |
|---|---|---|
| `url` | website key | your official site URL |
| `org.copeybara.release` | Safe | `sha256:<hex>;v=<n>` |
| `org.copeybara.manifest` | Safe | compact JSON, below |
| `org.copeybara.exits` | Safe | exit spec JSON, below (optional) |
| `org.copeybara.site` | Safe | `v=2;sha256=<hex>,<hex>,…` (optional) |
| `org.copeybara.extension` | Safe | `sha256:<hex>;v=<n>;tree=<hex>` (optional) |
| `org.copeybara.status` | Safe or watcher | `v=1;state=<ok\|degraded\|compromised>[;at=<unix>][;note=<urlencoded>]` |
| `org.copeybara.blocklist` | Safe or watcher | `{"v":1,"domains":["host",…]}` |

`<hex>` is 64 lowercase hex characters. `org.blackout.*` records from before the rename stay on chain, frozen, so kits saved before it keep working.

## release / extension

```text
sha256:9f2c…e41a;v=7
sha256:51ab…09cd;v=3;tree=c0de…77f1
```

`sha256` is the hash of the exact file users download; `v` is a positive integer that must go up with every release. `tree` (extension only) is a hash over the unpacked extension files.

## manifest

```json
{"v":1,"c":{"11155111":{"uniswap-v3":{"positionManager":{"a":"0x1238…","s":["0xac9650d8","0x0c49ccbe","0xfc6f7865"]}}}}}
```

`c[chainId][adapter][role] = { a: address, s: [selectors] }`, keys sorted. An empty `s` is a read-only contract. Adapters the reading kit does not know are skipped, never trusted. Generated by `copeybara manifest`; never write it by hand.

## exits

```json
{"kinds":{"vault":{ … ExitKind … }},"v":1}
```

`kinds` is keyed by the `spec` role in the manifest. Keys are sorted. See [Exit spec](exit-spec.md).

## site

```text
v=2;sha256=0b1d…,9ac3…
```

Sorted, deduplicated script hashes. The legacy `sha256:<hex>` (one hash) is still read.

## status

```text
v=1;state=compromised;at=1762480000;note=Unknown%20script%20on%20app.example.xyz
```

An empty record means `ok`. Notes are URL-encoded, at most 200 characters. **Status never blocks an exit:** the kit ignores it. Extensions use it to warn about or block your website.

## blocklist

```json
{"v":1,"domains":["app-example.xyz","example-claim.com"]}
```

Bare lowercase hostnames, sorted and deduplicated. A host matches a listed domain or any of its subdomains. Extensions refuse to let these pages reach a wallet.

## Reading them yourself

```bash
scripts/verify-kit.sh copeybara-kit.html yourprotocol.eth   # kit vs release, through 3 RPCs
pnpm copeybara verify                                      # every record vs your config
```
