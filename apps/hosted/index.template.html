Copeybara exit kit

A saved, verifiable emergency exit for DeFi positions. It keeps working when the protocol's website, domain or RPC provider fails or is hijacked.

1. Download

copeybara-kit.html (__SIZE__ bytes) · sha256

sha256 of this build:

__SHA__

This host is not trusted. Any mirror is fine, because the fingerprint in ENS is what you check.

2. Verify it yourself

Compare the file's fingerprint with the protocol's ENS release record org.copeybara.release, using a tool outside this page:

sha256sum copeybara-kit.html
scripts/verify-kit.sh copeybara-kit.html <protocol>.eth     # prints MATCH v=<n> or MISMATCH

Take the ENS name from the protocol's docs or where you deposited, never from the kit.

3. Run it

npx serve .        # or: python3 -m http.server

Open http://localhost:3000/copeybara-kit.html, connect your wallet and press Exit. Wallets do not inject into file:// pages. You can also open the kit here: its Release & exits tab reads the live ENS records without a wallet.

No analytics, no trackers, no server. Open source (MIT).
